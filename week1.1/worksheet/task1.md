# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | lists everything in the current directory  
|     cd directory_name       | moves into the directory called directory_name
|     cd ..                   | moves up one directory level
|     cd -                    | returns to the previous directory
|     mkdir directory_name    | creates a directory called directory_name
|     touch filename          | creates a file called filename in the current directory 
|     git status              | gives the current status of the git repository
|     git add -A              | allows you to save your changes, -A means all
|     git commit -m ""        | puts all the changes together in one commit, -m allows a message to be written
|     git push                | sends all the changes back to the remote github server
|     git pull                | retrieves changes from the remote github server
